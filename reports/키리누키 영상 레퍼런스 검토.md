# 키리누키 영상 레퍼런스 검토

조사일 2026-11-22. 실제 키리누키(切り抜き, 클립) 영상의 공개 정보와 편집 관례, 정책, 자동화 도구를 조사하고 stream2clip(v0.15.0)에 더 반영할 사항을 정리. 확인하지 못한 항목은 미확인으로 표기

## 1. 결론

| 항목 | 내용 |
|:---:|---|
| 영상 형태 | 표본 290개 중 세로 Shorts는 4%. 일본어 채널은 가로 10분 전후, 한국어와 영어 채널은 가로 2~3분이 중심. stream2clip의 기본값(9:16 Shorts)과 다름 |
| 이미 맞는 부분 | 채팅 급증 기반 검출(연구로 뒷받침), 원본 링크를 맨 위에 둔 설명란(실제 영상은 39% 이하만 맨 위), 음원 크레디트(실제 영상의 31%가 표기, DOVA와 OtoLogic이 최다), 무음 구간 제거, 모음 영상 챕터 |
| 가장 큰 빈칸 | 화자별 색 자막(합방), 제목과 썸네일 생성, 짧은 예고(ちょい見せ)와 상황 설명 자막, 독창성 점검(YouTube 재사용 콘텐츠 정책과 2026-10 Shorts 추천 변경) |
| 우선순위 | 6절. 1순위 6개는 모두 코어(numpy, Pillow, ffmpeg)로 구현 가능, 화자 분리만 선택 설치 패키지 필요 |

## 2. 조사 방법

| 항목 | 내용 |

## 8. 미확인 사항

- Shorts의 실제 비율(검색 결과는 Shorts를 적게 표시)
- 일본어 키리누키의 `ｗ`, `！？` 글자 효과, 정지 화면과 느린 재생, 화면 속 채팅 표시의 관례
- 한국어 클립의 화자 색, 원문 병기, 제목 괄호 관례
- 이세계아이돌, CHZZK, SOOP의 공식 2차 창작 원문
- 스텔라이브 가이드라인의 원문 세부(반영 전 직접 확인)
- 썸네일 실제 화면(영상을 받지 않아 문헌으로만 확인)
