# 실환경 검증 현황

자동 테스트와 별도로 실제 기기, 실제 서비스에서 확인한 범위와 미검증 범위. 요약은 README의 [알려진 제약](../README.md#알려진-제약) 참조

## 운영체제 및 화면

| &numsp;&numsp;&numsp;&numsp;환&NoBreak;경&numsp;&numsp;&numsp;&numsp; | 검증 내용 | 미검증 |
|:---:|---|---|
| Windows 11 | 실기기(1920×1080, 배율 125%, 모니터 1대)에서 전역 단축키 F8, F9(앱이 숨겨진 상태 포함), 커서 합성, 선택 영역과 캡쳐 및 녹화 결과의 일치, GIF, MP4, WebP, WebM, 투명 배경, 클립보드 복사 | 배율 100%, 150%, 175%는 동일 기기에서 Qt 배율 계수(`QT_SCALE_FACTOR`)로만 확인. 배율이 다른 모니터 2대 |

## 화면 언어

- 앱 화면 문구는 한국어, 일본어, 영어 제공. Windows 11에서 3개 언어 모두 화면을 표시하여 배치 확인
- 하이라이트 근거, 가이드라인 점검, VRM 검사, Shorts 경고 문구도 3개 언어 제공. 일본어, 영어 화면의 하이라이트 목록에서 표시 확인
- 명령줄의 진행 출력은 영어만 제공
- 일본어, 영어 번역은 원어민 검수 미실시

## 설치 프로그램

- GitHub Actions의 Windows 러너에서 빌드 후 3개 언어로 자동 설치, 설치된 프로그램의 시작 언어와 제거 확인
- 언어 선택 창 표시 확인(러너 화면 캡쳐)
- 화면 단계별 설치: Windows 11 실기기에서 v0.8.0 설치 프로그램을 자동 옵션 없이 실행하여 언어 선택 창(English, 日本語, 한국어 제공)에서 일본어 선택, 설치 위치, 설치 준비, 설치, 완료 화면까지 진행. 15개 확인 항목 통과
  - 설치 결과: 사용자 폴더의 `AppData\Local\Programs\stream2clip`에 프로그램, `language.txt`(`ja`), 제거 프로그램 생성. 시작 메뉴 바로 가기와 제거 항목 등록
  - 완료 화면의 실행 선택으로 앱이 일본어 화면으로 시작. 명령줄 프로그램의 `language`도 `ja`
  - 제거: 제거 프로그램의 확인 창을 거쳐 프로그램, 바로 가기, 제거 항목 삭제 확인
- ffmpeg 내려받기 작업: GitHub Actions의 Windows 러너에서 ffmpeg가 PATH에 없는 상태로 확인
  - 작업을 선택한 자동 설치: 고정한 빌드(115MB)를 내려받아 SHA-256 확인 후 사용자 폴더에 `ffmpeg.exe`, `ffprobe.exe`, 라이선스 문서만 배치. 설치된 프로그램의 `setup`이 필수 구성요소 모두 있음으로 판정(종료 코드 0), 내려받은 ffmpeg로 GIF 클립 제작
  - 작업을 해제한 자동 설치: ffmpeg를 내려받지 않으며 `setup`의 종료 코드 1
  - 제거: 프로그램과 함께 내려받은 ffmpeg 삭제
  - 추가 작업 화면: ffmpeg 내려받기 선택, 바탕 화면 바로 가기 미선택 상태로 표시(러너 화면 캡쳐)
  - 프로그램 자체 내려받기(`setup --ffmpeg`): 115MB 수신, SHA-256 확인, 내려받은 ffmpeg로 클립 제작
- 구성요소 점검 창(v0.13.0): Windows 11 실기기에서 창을 열어 이 PC의 실제 구성요소 9개(ffmpeg와 버전, 얼굴 검출 모델, OBS 응답 없음, 자막 글꼴 등)가 표시됨을 3개 언어 화면으로 확인. 창에서의 실제 내려받기는 미검증(가짜 내려받기로 테스트)
- ffmpeg 내려받기 작업의 화면 단계별 확인: Windows 11 실기기에서 v0.10.0 설치 프로그램을 ffmpeg가 PATH에 없는 상태로 실행하고 한국어 선택. 22개 확인 항목 통과
  - 추가 작업 화면: **ffmpeg 내려받기 (녹화와 영상 변환에 필요, 115 MB)**가 첫 항목으로 선택되어 표시
  - 해제 후 설치: 설치 준비 화면의 목록에 미표시, 내려받은 파일 없음, 완료 화면에 ffmpeg 안내 표시
  - 완료 화면에서 실행된 앱: 시작 화면 상단에 ffmpeg 안내와 내려받기 버튼 표시
  - 설치된 프로그램의 `setup`: ffmpeg가 PATH에 없으면 종료 코드 1, 있으면 0
  - 이 확인에서 완료 화면의 ffmpeg 안내가 잘려 표시되지 않는 문제를 발견하여 수정 후 재확인
- 미검증: 화면 단계별 설치에서 내려받기를 선택한 경우의 진행 화면, 취소, 연결 실패 안내 창. 앱 시작 화면 버튼의 실제 내려받기(가짜 내려받기로 테스트). 내려받기 자체는 러너의 자동 설치와 `setup --ffmpeg`로 확인
- 코드 서명 미적용. Smart App Control 사용 PC에서 3회 빌드한 결과 `stream2clip.exe`는 매회, `stream2clip-gui.exe`는 1회 차단(2회는 실행). Smart App Control을 사용하지 않는 상태에서는 차단 없이 실행

## 실행 파일

Windows 11 실기기에서 v0.8.0 zip의 실행 파일을 직접 실행하여 확인(파이썬 소스가 아닌 빌드된 프로그램 기준, 13개 확인 항목 통과). v0.9.0, v0.10.0의 실행 파일도 같은 항목 통과

| &numsp;&numsp;&numsp;&numsp;항&NoBreak;목&numsp;&numsp;&numsp;&numsp; | 확인 내용 |
|:---:|---|
| 시작 | `stream2clip.exe --version`, 내장 yt-dlp 실행, `stream2clip-gui.exe` 창 표시와 종료 |
| 클립 제작 | pip 레이아웃과 별도 아바타 영상 합성, 문장 경계 맞춤, 자막 스타일과 위치, 설치 폰트 조회(일본어 자막에 Yu Gothic 선택) |

## 방송 기록기

- 환경: OBS Studio 33.0.1(obs-websocket 5.7.6, Windows 11, 캔버스 1920×1080, 출력 1280×720). VTube Studio는 이 PC에 미설치
- 방법: 장면 2개와 색상 소스(VTube Studio 화면 대역), 음성 파일 2개(트랙 1에 게임 소리, 트랙 1과 2에 마이크)를 임시로 구성하고 obs-websocket으로 장면 전환, 녹화 시작과 중지, 소스 이동 수행. 확인 후 임시 장면 삭제, OBS 설정은 백업으로 복원
- `session record` 확인 항목
  - 캔버스 크기, 장면 전환, 녹화 시작과 중지 기록. 녹화 시작은 요청 후 0.1초, 장면 전환은 0.3초 뒤 기록(OBS가 전환 효과 종료 시점에 통지)
  - 녹화 파일에서 장면이 바뀌는 시점과 세션의 장면 시각 차이 0.1초(`--session-origin record`)
  - 소스 배치 4종(자르기와 우하단 정렬, 경계 상자, 캔버스보다 큰 중앙 정렬, 좌상단 절반 크기): 계산한 영역과 OBS가 그린 영역의 차이 1픽셀 이내
  - 시청자 투표 표시, 스트리머의 채팅 표시, OBS 위젯 페이지와 상태 응답
  - VTube Studio 미실행 상태: 연결 대기 안내 후 나머지 기록 계속
- 실측으로 수정한 사항 4건
  - 한 부분의 연결 재시도가 다른 부분의 시각을 늦추던 문제. VTube Studio 미실행 시 장면 시각이 최대 2초 늦게 기록됨. 부분별 스레드로 분리 후 0.3초
  - 장면 전환 없이 옮긴 소스의 배치가 최대 15초 뒤 기록되던 문제. OBS의 배치 변경 통지를 구독하여 0.4초
  - 녹화 중에 기록기를 시작하면 연결 시점이 녹화 시작으로 기록되던 문제. OBS가 알려 주는 진행 시간으로 시작 시점 계산(실측 오차 0.7초)
  - 기록 종료 직전의 표시에 대한 리플레이 저장 요청이 누락될 수 있던 문제
- 세션에서 클립까지: 실제 녹화 파일과 세션으로 하이라이트 검출(표시 구간), `--layout stack --avatar session`, `--audio-track 1 --trim-silence --transcribe small` 실행. 마이크 트랙 기준 자막 인식과 무음 11.6초 제거, 트랙 미지정 시 게임 소리로 인해 제거 구간 없음
- 앱: 기록기 창의 기록 시작, **지금 표시**, 기록 중지, **하이라이트 찾기**와 하이라이트 창의 세션 검출, **세션에서** 확인(버튼은 Qt 이벤트로 실행)
- 아바타 박스: VTube Studio 미설치로 실제 외곽선 미확보. 실제 OBS 배치에 합성 외곽선(화면 가운데 절반)을 더한 세션으로 확인. 박스 중심이 모델 중심과 일치, 상단은 모델 위 5픽셀
- 아바타 별도 녹화(`--avatar-record`): Source Record 플러그인이 없는 실제 OBS에서 사유(요청 상태 600)를 기록하고 나머지 기록을 계속하는 것 확인. 플러그인으로의 실제 녹화 시작과 오프셋 정확도는 미검증
- 미검증: VTube Studio 연결과 플러그인 허용 창, 실제 모델의 외곽선과 파라미터, 본인 채널의 방송 채팅(CHZZK, SOOP, Twitch)과 시청자 투표, 명령줄의 Enter 표시와 F11(실제 키 입력), OBS 28~32, 송출 시작 기준(`--session-origin stream`)과 플랫폼 다시보기의 시각 차이
- CHZZK 공식 Open API: 공식 문서(인증, 세션, 이벤트 형식) 기준으로 작성하고 가짜 서버로 테스트. 애플리케이션 등록과 실제 로그인, 실제 Socket.IO 서버 연결은 미검증

## OBS 연동

- 환경: OBS Studio 33.0.1(obs-websocket 5.7.6, Windows 11)
- 확인 항목: 비밀번호 인증(잘못된 비밀번호, 누락된 비밀번호 거절), 리플레이 버퍼 시작 및 저장, 마지막 5초 GIF(명령줄), 마지막 3초 MP4(앱의 리플레이 저장 버튼)
- 안내 문구에 반영한 사항 2건
  - 신규 설치한 OBS는 리플레이 버퍼가 꺼진 상태. 설정의 출력 메뉴에서 사용 설정 필요
  - 장면에 소스가 없으면 OBS가 "소스 없음" 확인 창을 표시하고 버퍼를 시작하지 않음
- 미검증: OBS 28~32, 다른 PC의 OBS(원격 연결)

## 라이브 모드

- 명령줄: 실제 OBS와 실제 YouTube 라이브 채팅(분당 약 25개)으로 확인. 버퍼가 꺼진 경우 즉시 안내, 급증 2회에 35초 클립 2개를 55초 리플레이에서 잘라 저장. 이 확인에서는 수 분 내 발동하도록 임계값을 1로 하향
- 런처: 동일 환경에서 시작, 클립 저장, 중지 확인(임계값 하향 설정)
- 기본 설정 관찰: 실제 방송 1개를 30분 관찰하여 6회 발동. 이 결과에 따라 구간당 최소 메시지 수를 8로 조정([DETECTION.md](DETECTION.md#실제-방송-관찰에-따른-조정))
- Twitch 채팅: 실제 방송 중인 채널에 익명으로 접속하여 4분간 수신(메시지 2,381개, 임계값을 2로 낮춘 설정에서 1회 발동). 메시지 시각과 PC 시계의 차이는 약 1초. OBS는 사용하지 않고 급증 판정까지 확인
- Twitch 채팅과 OBS: 실제 방송 중인 Twitch 채널의 채팅과 실제 OBS Studio 33.0.1로 확인. 임계값을 1로 낮춘 설정에서 급증 2회에 35초 클립 2개를 54초, 56초 리플레이에서 잘라 저장(4분 2초 소요, 메시지 268개)
- 표시 명령과 OBS: 채팅 파일에 스트리머 역할의 `!clip`을 기록하여 기본 임계값, 준비 시간 이전 상태에서 35초 클립 1개 저장 확인. 시청자의 `!clip`은 발동하지 않음
- CHZZK, SOOP 채팅: 실제 방송 중인 채널에 로그인 없이 접속하여 기본 설정으로 각 5분간 수신(OBS 미사용). CHZZK는 메시지 1,021개에서 1회 발동(점수 3.7, 평소의 2.8배), SOOP은 메시지 1,543개(별풍선 포함)에서 발동 없음. CHZZK 메시지 시각과 PC 시계의 차이는 약 1.5초, SOOP 메시지는 시각 정보가 없어 도착 시각 사용
- SOOP 후원 패킷: 실제 방송 6개를 150초 관찰하여 별풍선 3건, 애드벌룬 2건, 영상풍선 1건의 항목 위치 확인. 구독 및 팔로우 알림은 관찰하지 못하여 수신하지 않음
- CHZZK, SOOP 채팅과 OBS: 실제 방송 중인 채널의 채팅과 실제 OBS Studio 33.0.1로 확인. 임계값을 1로 낮춘 설정에서 각 1회 발동하여 35초 클립을 55초, 59초 리플레이에서 잘라 저장(10개 확인 항목 통과)
- 미검증: 기본 임계값에서의 클립 절단 위치와 실제 장면의 일치 여부(종료된 방송의 채팅으로만 측정). CHZZK, SOOP의 성인 인증 및 비밀번호 방송
