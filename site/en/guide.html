Installation

Windows installer

  1. Download the Windows installer (setup.exe) from the releases page and run it
  2. Choose the language on the first page: Korean, Japanese or English. It is used for the installer and for the app
  3. Confirm the folder. No administrator rights needed
  4. On the additional tasks page, keep Download ffmpeg ticked and install. ffmpeg (115 MB), which video conversion needs, is downloaded during the installation. The task is not shown on a PC that already has ffmpeg
  5. Start stream2clip from the Start menu
  • Download unticked or failed: the Download ffmpeg button at the top of the app's start window does it again
  • Checking components: Check components at the top right of the start window lists what each feature needs, whether it is there and how to get it. On the command line: stream2clip setup
  • Without installing: download the zip file, unzip it to any folder and run stream2clip-gui.exe. The Download ffmpeg button on the start window gets ffmpeg
  • The language of the app can be changed later at the bottom of the launcher
  • Removal: uninstall stream2clip in the installed apps list of the Windows settings. The downloaded ffmpeg is removed with it

Note

  • Not code signed. Windows SmartScreen may show a warning
  • Smart App Control may block the programs. Use the Python package in that case
  • File integrity: compare the SHA-256 value on the releases page with the result of the command below
Get-FileHash .\stream2clip-*-windows-x64.zip -Algorithm SHA256

Python package

  • Requirements: Python 3.10 or later, ffmpeg
  • Systems: Windows, macOS, Linux
pip install "stream2clip[gui,ingest,obs] @ git+https://github.com/BudongJW/stream2clip"
stream2clip gui
ExtraFunction
asrSpeech-to-text subtitles (Whisper)

Extras are added inside the square brackets of the install command. Speech-to-text subtitles and YouTube upload are provided by the Python package.

Basic use

ShortcutFunction
F8Capture a screen area and open it in the editor
F9Select an area and start recording. Press again to stop and save
F10Save the OBS replay buffer and convert it to a clip. Only when switched on in the launcher
  • Shortcuts work while other programs are in use
  • Default save location: Videos\stream2clip. Changed with Change folder at the bottom of the launcher
  • Interface languages: Korean, Japanese, English. A change applies after a restart
  • Settings are saved automatically and restored at the next start. Passwords are not saved

  • F8: freezes the screen and sends the dragged area to the editor
  • Capture everything: capture of all monitors
  • Open an image to edit: editing of PNG, JPG and WebP files

Screen recording

  1. Choose the output format, frame rate and size in the launcher
  2. Press F9 and drag the area to record. Recording starts at once
  3. Press F9 again to stop and save
FormatCharacteristics
GIFPlays almost everywhere. Transparency has two levels
MP4Small files
WebPGood picture quality. Soft transparent edges
WebMVideo with transparency

Transparent background

  • Output of GIF, WebP or WebM with a chosen colour (a green screen, for example) removed
  • Eyedropper picks the colour to remove, Tolerance sets how similar a colour has to be

Highlight clips

Detection, adjustment of spans and export are done in Find highlights in the launcher.

Input

FieldContent
VideoArchive file or stream address
ChatChat replay file. Collected automatically for a stream address
InfoOptional. Title and address of the source stream, used for the description text
SubtitlesOptional. SRT or WebVTT file

Start from a stream address

  • A stream address in the Video field collects the chat replay and the stream information automatically
  • Only the selected spans of the video are downloaded at export
  • Collected data is kept per stream in the sources folder of the save folder and reused at the next run
  • The preview appears once the span has been downloaded
  • Loudness, laughter and singing analysis are available for a video file
  • Supported: YouTube, CHZZK and SOOP archives

Procedure

  1. Run Find highlights. Spans with chat activity above normal appear on the timeline and in the list
  2. Adjust spans on the timeline. Drag the middle to move, drag an edge to change the start or end, use the wheel or a double click to zoom
  3. Select the spans to export and choose the layout and format
  4. Run Export clips. The save folder receives the clips, subtitle files (.ass) and description texts (.txt)

Video, chat, info and subtitle files can be dropped onto the window.

NameComposition

Detection options

  • Threshold: a lower value finds more spans, a higher value keeps only strong reactions
  • Up to: upper limit of the number of spans
  • Songs: marks or leaves out spans that overlap singing. Clips of singing streams are often restricted for copyright reasons

Download of a whole stream

The command below saves the video, chat and stream information to the vod folder when the whole video is needed.

stream2clip.exe fetch "STREAM_ADDRESS" -o vod --video

OBS replay

Saves the recent moments held in the OBS replay buffer and converts them to a clip.

Preparation in OBS

  1. Enable the replay buffer in the Output section of the OBS settings. It is off after a new installation
  2. Enable the server in the WebSocket server settings of the OBS Tools menu and check the password
  3. Start the replay buffer in OBS when the stream starts

Settings and use in stream2clip

  1. Enter the OBS password in Connection in the launcher. The password is not saved and is entered at every start
  2. Set the length to keep in Last and run Save replay. The format and size of the recording settings are used
  3. With F10 checked, F10 saves while other programs are in use. Other programs do not receive F10 meanwhile

Live mode

Detects a chat surge during a stream, saves the OBS replay buffer and cuts the moment out as a clip of about 35 seconds.

Prerequisites

  • OBS replay buffer running and the WebSocket connection set up
  • Maximum replay time in OBS of 60 seconds or more. The default of 20 seconds loses the beginning of the moment

Procedure

  1. Enter a live address on YouTube, Twitch, CHZZK or SOOP in the Live mode field of the launcher
  2. Choose the sensitivity. High saves on small surges, Low only on large ones
  3. Run Start live mode. A chat surge creates a clip named live_DATE_TIME in the save folder
  4. End with Stop live mode

How it decides

  • Chat volume, number of chatters, reaction words and paid messages per 5 seconds are compared with the 15 minutes before
  • The first 2 minutes only collect the baseline. Clips are at least 90 seconds apart
  • The moment is taken to be 8 seconds before the surge. The clip keeps 20 seconds before and 10 seconds after
  • !clip typed in chat by the streamer or a moderator saves a clip at once, surge or not
  • Supported: live YouTube streams, Twitch, CHZZK, SOOP. Adult-only and password streams on CHZZK and SOOP are excluded

Command line

stream2clip.exe live "https://www.youtube.com/watch?v=VIDEO_ID" -o clips
OptionFunction
--thresholdLevel that triggers a save. Default 3.5. A higher value saves less often
--no-obsReports surges without saving
--simulateShows when a finished stream would have triggered, from its chat file
--delayReaction delay of viewers. Streamers add their stream latency

Stream recorder

Records the chat, markers, OBS scenes and the position and expression of the VTube Studio avatar into a session file during the stream, for making clips afterwards. OBS records the video.

Procedure

  1. Open Stream recorder in the clip area of the start window
  2. Enter the live address of the streamer's own channel and choose whether to use OBS and VTube Studio. In VTube Studio, switch the API on in the settings and press Allow in the plugin popup the first time
  3. Enter the name of the OBS source that shows VTube Studio. It places the avatar box when clips are made
  4. Run Start recording. At a moment to keep, press Mark now or F11 (when switched on)
  5. After the stream, Stop recording, then Find highlights opens the session file in the highlights window

What is recorded and what for

  • Chat and markers: highlights are found without downloading the chat replay. Marked moments always become clips
  • OBS scenes: highlights in chosen scenes such as a waiting or ending screen are left out
  • VTube Studio outline and its place in OBS: the avatar box of vertical clips
  • Second 0 of the video is when OBS started streaming, or recording when it did not stream
  • Viewer votes: 3 viewers typing !clip within 30 seconds leave a marker
  • Chatters are recorded only as values that do not identify them, and the file stays on this PC

Command line

stream2clip.exe session record --chat "https://chzzk.naver.com/live/CHANNEL_ID" --vts --vts-source "VTube Studio"
stream2clip.exe auto vod.mp4 -o clips --session session.jsonl --skip-scene waiting --layout stack --avatar session

Command line

Every function of the app is available through stream2clip.exe. Used for processing several streams in one go.

CommandFunction
fetchDownload of stream information, chat, video and subtitles from a stream address
autoFrom a video with chat, or from a stream address, to finished clips
highlights, clipsDetection and export as separate steps
convertCuts a span and area of a video and converts it to GIF, WebP or MP4
record, captureRecording and capture of a screen area
replay, liveOBS replay save, live mode
checkCompares a description text with the guideline items of an agency
 
stream2clip.exe auto "STREAM_ADDRESS" --top 5 -o clips
stream2clip.exe auto vod\video.mp4 --chat vod\VIDEO_ID.live_chat.json --info vod\info.json -o clips
stream2clip.exe convert vod.mp4 --start 1:02:03 --end 1:02:18 --width 480 -o highlight.webp

All options: add --help to a command. More examples in the README (Korean).

Troubleshooting

SymptomAction
Program blockedCaused by the missing code signature. Use the Python package where Smart App Control is on
Newer version noticeShown at the top of the start window. Open the download page gets the new installer, Stop asking ends the check. It asks at most once a day and sends nothing about the user
ffmpeg not foundUse the Download ffmpeg button on the app's start window, or stream2clip setup --ffmpeg on the command line. After installing it yourself: Look again, or restart the program
No spans foundLower the threshold and run again. Check that the chat file belongs to the stream
YouTube asks for sign-inPass browser cookies on the command line with --cookies-from-browser chrome
Replay buffer not runningEnable the replay buffer in the Output section of the OBS settings and start it. OBS does not start the buffer for a scene without sources
No connection to OBSCheck that the WebSocket server is enabled, and the password and port (default 4455)
Live mode clip misses its beginningSet the maximum replay time in OBS to 60 seconds or more
F8 or F9 without effectClose the other program that uses the same key and restart

Other problems: GitHub issues.

Copyright and guidelines

  • A clip is a derivative work of the source stream. The guidelines of the creator and of the agency apply
  • Choosing an agency in the guideline list of the export settings writes a description text with the source title and address and checks the guideline items
  • Items checked: members-only stream, public archive, channel registration, disclosure of AI use
  • The results are for reference and are not legal advice. Read the original guidelines of the agency and the creator before uploading
