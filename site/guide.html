설치

Windows 설치 프로그램

  1. 릴리즈 페이지에서 Windows용 설치 프로그램(setup.exe) 다운로드 후 실행
  2. 첫 화면에서 언어 선택: 한국어, 日本語, English. 선택한 언어가 설치 화면과 앱의 표시 언어로 적용
  3. 설치 위치 확인. 관리자 권한 불필요
  4. 추가 작업 화면에서 ffmpeg 내려받기 선택 유지 후 설치. 영상 변환에 필요한 ffmpeg(115MB)를 설치 과정에서 내려받으며, ffmpeg가 이미 있는 PC에서는 이 항목이 표시되지 않음
  5. 시작 메뉴에서 stream2clip 실행
  • ffmpeg 내려받기를 해제하였거나 실패한 경우: 앱 시작 화면 상단의 ffmpeg 내려받기 버튼으로 다시 진행
  • 설치 없이 사용: zip 파일 다운로드 후 원하는 폴더에 압축 해제, stream2clip-gui.exe 실행. ffmpeg는 시작 화면의 ffmpeg 내려받기 버튼으로 준비
  • 구성요소 확인: 시작 화면 우측 상단의 구성요소 점검에서 기능별 필요 구성요소의 유무와 해결 방법 표시. 명령줄에서는 stream2clip setup
  • 앱의 표시 언어는 설치 후에도 런처 하단에서 변경 가능
  • 제거: Windows 설정의 설치된 앱 목록에서 stream2clip 제거. 내려받은 ffmpeg도 함께 삭제

참고

  • 코드 서명 미적용. Windows SmartScreen 경고가 표시될 수 있음
  • Smart App Control 사용 환경에서는 실행이 차단될 수 있으며, 이 경우 파이썬 패키지 설치 사용
  • 파일 무결성은 릴리즈 페이지의 SHA-256 값과 아래 명령의 결과를 대조하여 확인
Get-FileHash .\stream2clip-*-windows-x64.zip -Algorithm SHA256

파이썬 패키지

  • 요구 사항: Python 3.10 이상, ffmpeg
  • 지원 운영체제: Windows, macOS, Linux
pip install "stream2clip[gui,ingest,obs] @ git+https://github.com/BudongJW/stream2clip"
stream2clip gui

화면 캡쳐 및 편집

  • F8: 화면 정지 후 드래그한 영역을 편집기로 전달
  • 전체 화면 캡쳐: 모든 모니터 캡쳐
  • 이미지 열어 편집: PNG, JPG, WebP 파일 편집

  • 자르기 도구: 원본을 유지한 상태로 남길 영역만 지정

화면 녹화

  1. 런처에서 출력 형식, 프레임, 크기 선택
  2. F9 입력 후 녹화 영역 드래그. 즉시 녹화 시작
  3. F9 재입력 시 정지 및 저장
형식특징
GIF재생 호환성 높음. 투명도는 2단계
MP4파일 용량 작음
WebP화질 우수. 부드러운 투명 가장자리 지원
WebM투명 영상 지원

투명 배경 녹화

  • 지정한 색상(그린스크린 등)을 제거한 GIF, WebP, WebM 출력
  • 스포이드로 제거할 색상 지정, 허용 범위로 유사 색상의 제거 범위 조정

하이라이트 클립 제작

런처의 하이라이트 찾기에서 검출, 구간 조정, 내보내기를 수행.

입력 자료

항목내용
영상다시보기 파일 또는 방송 주소
채팅채팅 다시보기 파일. 방송 주소 입력 시 자동 수집
정보선택 항목. 원본 제목과 주소를 설명란 작성에 사용
자막선택 항목. SRT, WebVTT 파일

방송 주소로 시작

  • 영상 칸에 방송 주소 입력 시 채팅 다시보기와 방송 정보를 자동 수집
  • 내보내기 단계에서 선택한 구간의 영상만 다운로드
  • 수집 자료는 저장 폴더의 sources 폴더에 방송별로 보관하며 재실행 시 재사용
  • 미리보기는 해당 구간의 다운로드 완료 후 표시
  • 음량, 웃음소리, 노래 구간 분석은 영상 파일 입력 시 사용 가능
  • 지원 대상: YouTube, CHZZK, SOOP 다시보기

작업 절차

  1. 하이라이트 찾기 실행. 채팅 반응이 평소보다 높은 구간이 타임라인과 목록에 표시
  2. 타임라인에서 구간 조정. 가운데 드래그는 이동, 가장자리 드래그는 시작과 끝 조정, 휠 또는 더블클릭은 확대
  3. 내보낼 구간 선택 후 레이아웃과 형식 지정
  4. 클립 내보내기 실행. 저장 폴더에 클립, 자막 파일(.ass), 설명란(.txt) 생성

영상, 채팅, 정보, 자막 파일은 창에 끌어다 놓아 입력 가능.

모음 영상과 편집 프로그램 연계

항목내용
출처 표기입력한 문구를 클립 왼쪽 위에 작게 표시. 예: 원본: 채널 이름
조용한 부분 줄이기클립 안에서 0.7초 넘게 조용한 부분을 짧은 쉼으로 단축. 자막도 함께 이동. 음량 기준이므로 게시 전 결과 확인 필요
모음 영상선택 시 내보낸 클립을 방송 순서대로 이어 붙인 compilation.mp4와 챕터 목록 compilation.txt를 함께 저장
편집용 내보내기체크한 구간을 컷 목록 highlights.edl, 타임라인 마커 markers.edl, 타임스탬프 목록 timestamps.txt로 저장. DaVinci Resolve, Premiere Pro 등에서 가져와 이어서 편집

이름구성
blur방송 화면을 중앙에 배치하고 상하 여백을 흐림 처리한 배경으로 채움
center화면 중앙부를 세로 화면에 맞춰 확대. 좌우 영역 잘림

아바타 영상stack, pip에서 선택 사용. 아바타만 녹화한 영상을 지정하면 초록 배경을 제거하여 합성. 투명 배경 영상은 그대로 사용

검출 옵션

  • 임계값: 낮을수록 검출 구간 증가, 높을수록 반응이 큰 구간만 검출
  • 최대 개수: 검출할 구간 수의 상한
  • 노래 구간: 노래와 겹치는 구간 표시 또는 제외. 노래 방송은 저작권 문제로 클립 제작이 제한되는 경우가 많음

방송 자료 일괄 다운로드

영상 전체가 필요한 경우 아래 명령으로 영상, 채팅, 방송 정보를 vod 폴더에 저장.

stream2clip.exe fetch "방송 주소" -o vod --video

자막 및 번역

항목내용
자막 파일SRT, WebVTT 지원. YouTube 자동 자막 사용 가능
카라오케발화 단어에 맞춰 색상 변경. 단어별 시각 정보가 있는 자막에 적용
스타일모양 4종(기본, 상자, 분홍 강조, 작게)과 위치 3종(아래쪽, 가운데, 위쪽) 선택. 폰트는 자막의 언어에 맞춰 자동 선택
문장 경계 맞춤자막 파일이 있는 경우 구간의 시작과 끝을 자막 줄의 경계로 이동. 이동 한도 3초. 하이라이트 찾기 실행 시 적용
받아쓰기자막이 없는 경우 음성에서 자막 생성(Whisper). 파이썬 패키지에서 제공
번역번역기 목록의 번역기 파일 고르기에서 translators\openai_compatible.py 선택 시 OpenAI 호환 주소(로컬 Ollama 등)로 번역
용어집원문과 번역어 두 열로 구성한 CSV. 인명 등 고정 표기에 사용
원문 병기원문과 번역문을 두 줄로 표시
  • 번역 서비스는 내장되어 있지 않으며 사용자가 번역기를 연결
  • 번역 품질은 연결한 모델에 따라 상이

OBS 리플레이 저장

OBS의 리플레이 버퍼에 보관된 최근 구간을 저장하여 클립으로 변환.

OBS 사전 설정

  1. OBS 설정의 출력 메뉴에서 리플레이 버퍼 사용 설정. 신규 설치 시 기본값은 사용 안 함
  2. OBS 도구 메뉴의 WebSocket 서버 설정에서 서버 사용 설정 및 비밀번호 확인
  3. 방송 시작 시 OBS에서 리플레이 버퍼 시작

stream2clip 설정 및 사용

  1. 런처의 연결 설정에 OBS 비밀번호 입력. 비밀번호는 저장하지 않으므로 실행 시마다 입력
  2. 마지막 항목에서 보존할 길이 지정 후 리플레이 저장 실행. 화면 녹화 설정의 형식과 크기로 저장
  3. F10 선택 시 다른 프로그램 사용 중에도 F10으로 저장. 사용 중에는 다른 프로그램이 F10 입력을 받지 못함

라이브 모드

방송 중 채팅 급증을 감지하여 OBS 리플레이 버퍼를 저장하고 해당 장면을 약 35초 길이의 클립으로 생성.

사전 조건

  • OBS 리플레이 버퍼 실행 및 WebSocket 연결 설정 완료
  • OBS 최대 리플레이 시간 60초 이상. 기본값 20초에서는 장면 앞부분이 누락

사용 절차

  1. 런처의 라이브 모드 칸에 YouTube, Twitch, CHZZK, SOOP의 라이브 주소 입력
  2. 민감도 선택. 높음은 작은 급증에도 저장, 낮음은 큰 급증에만 저장
  3. 라이브 모드 시작 실행. 채팅 급증 시 저장 폴더에 live_날짜_시각 형식의 클립 생성
  4. 라이브 모드 중지로 종료

동작 기준

  • 5초 단위의 채팅량, 참여자 수, 반응 어휘, 후원 내역을 직전 15분과 비교
  • 시작 후 2분간은 기준 수집만 수행하며 클립 간 최소 간격은 90초
  • 급증 8초 전을 장면 시점으로 판단하여 앞 20초, 뒤 10초를 포함
  • 스트리머 또는 모더레이터가 채팅에 !clip 입력 시 급증 여부와 무관하게 즉시 저장
  • 지원 대상: YouTube 라이브 방송, Twitch, CHZZK, SOOP. CHZZK, SOOP의 성인 인증 및 비밀번호 방송은 제외

명령줄 실행

stream2clip.exe live "https://www.youtube.com/watch?v=VIDEO_ID" -o clips
옵션기능
--threshold발동 기준. 기본값 3.5. 높일수록 저장 횟수 감소
--no-obs저장 없이 급증 발생만 출력
--simulate종료된 방송의 채팅 파일로 발동 시점 확인
--delay시청자 반응 지연 시간. 방송 송출자는 송출 지연만큼 증가시켜 사용

명령줄 사용

앱의 모든 기능은 stream2clip.exe로 실행 가능. 다수의 방송을 일괄 처리할 때 사용.

명령기능
fetch방송 주소에서 방송 정보, 채팅, 영상, 자막 다운로드
auto영상과 채팅 또는 방송 주소로 하이라이트 검출부터 클립 생성까지 수행
highlights, clips검출과 내보내기를 개별 수행
convert영상의 구간과 영역을 잘라 GIF, WebP, MP4로 변환
record, capture화면 영역 녹화 및 캡쳐
replay, liveOBS 리플레이 저장, 라이브 모드
check설명란을 기획사 가이드라인 항목과 대조
 
stream2clip.exe auto "방송 주소" --top 5 -o clips
stream2clip.exe auto vod\video.mp4 --chat vod\VIDEO_ID.live_chat.json --info vod\info.json -o clips
stream2clip.exe convert vod.mp4 --start 1:02:03 --end 1:02:18 --width 480 -o highlight.webp

전체 옵션은 각 명령에 --help를 붙여 확인. 추가 예시는 README 참조.

증상조치
프로그램 실행 차단코드 서명 미적용으로 인한 차단. Smart App Control 사용 환경에서는 파이썬 패키지 설치 사용
새 버전 알림시작 화면 상단에 표시. 내려받기 페이지 열기로 새 설치 프로그램 다운로드, 알림 끄기로 확인 중지. 확인은 하루 1회 이내이며 사용자 정보는 전송하지 않음
ffmpeg 미검출앱 시작 화면의 ffmpeg 내려받기 버튼 사용. 명령줄에서는 stream2clip setup --ffmpeg. 직접 설치한 경우 다시 확인 버튼 또는 프로그램 재실행
검출 구간 없음임계값을 낮춰 재실행. 채팅 파일이 해당 방송의 자료인지 확인
YouTube 로그인 요구명령줄에서 --cookies-from-browser chrome 옵션으로 브라우저 쿠키 전달
리플레이 버퍼 미실행OBS 설정의 출력 메뉴에서 리플레이 버퍼 사용 설정 후 버퍼 시작. 장면에 소스가 없으면 OBS가 버퍼를 시작하지 않음
OBS 연결 실패WebSocket 서버 사용 여부, 비밀번호, 포트(기본값 4455) 확인
라이브 모드 클립의 앞부분 누락OBS 최대 리플레이 시간을 60초 이상으로 변경
F8, F9 미동작동일한 키를 사용하는 다른 프로그램 종료 후 재실행

기타 문제는 GitHub 이슈에 등록.

저작권 및 가이드라인

  • 클립은 원본 방송의 2차 창작물에 해당하며 원저작자와 소속 기획사의 가이드라인 적용 대상
  • 내보내기 설정의 가이드라인에서 기획사 선택 시 원본 제목과 주소를 포함한 설명란 작성 및 점검 항목 확인
  • 점검 항목: 멤버십 한정 방송 여부, 아카이브 공개 여부, 채널 등록 여부, AI 사용 표기
  • 점검 결과는 참고 자료이며 법적 판단이 아님. 업로드 전 각 기획사와 방송인의 가이드라인 원문 확인 필요
