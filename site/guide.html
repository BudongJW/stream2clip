Manual · v0.4

stream2clip 설명서

설치부터 첫 클립, OBS 연동, 자주 막히는 곳까지.

Windows 실행 파일 v0.4.0 기준입니다. 다음 버전 표시가 붙은 기능은 아직 실행 파일에 없고, 파이썬 설치에서 먼저 쓸 수 있습니다.

01설치

Windows 실행 파일

  1. 릴리즈 페이지에서 stream2clip-…-windows-x64.zip을 받습니다.
  2. 원하는 폴더에 압축을 풉니다. 설치 프로그램은 없습니다.
  3. ffmpeg를 준비합니다. 영상을 자르고 변환하는 프로그램입니다. 
    winget install Gyan.FFmpeg
    설치한 뒤 터미널을 새로 열어야 인식됩니다. 설치하지 않고 ffmpeg.exe · ffprobe.exe 두 파일을 실행 파일 옆에 두어도 됩니다.
  4. stream2clip-gui.exe를 실행합니다.

코드 서명이 없는 프로그램입니다. Windows SmartScreen 경고가 뜰 수 있고, Smart App Control이 켜진 PC에서는 실행이 막힐 수 있습니다. 막힌다면 아래의 파이썬 설치를 쓰세요. 받은 파일이 원본인지는 릴리즈 페이지의 SHA-256과 비교해 확인할 수 있습니다.

Get-FileHash .\stream2clip-*-windows-x64.zip -Algorithm SHA256

파이썬으로 설치 (Windows · macOS · Linux)

Python 3.10 이상과 ffmpeg가 필요합니다.

pip install "stream2clip[gui,ingest,obs] @ git+https://github.com/BudongJW/stream2clip"
stream2clip gui

자막 받아쓰기는 [asr], 아바타 자동 찾기는 [detect], YouTube 업로드는 [upload]를 대괄호 안에 더합니다.

02처음 실행

단축키하는 일
F8화면의 영역을 캡쳐해 편집기로 엽니다
F9영역을 고르면 바로 녹화, 다시 누르면 정지하고 저장합니다
F10(런처에서 켰을 때만) OBS 리플레이 버퍼를 저장해 클립으로 만듭니다
  • 단축키는 다른 프로그램을 쓰는 중에도 동작합니다.
  • 저장 위치는 아래의 폴더 변경으로 바꿉니다. 처음에는 동영상\stream2clip입니다.
  • 화면 언어(한국어 · 日本語 · English)는 오른쪽 아래에서 고르고, 다음 실행부터 적용됩니다.
  • 고른 설정은 다음 실행 때 그대로 돌아옵니다. 비밀번호는 저장하지 않습니다.

03캡쳐와 편집

F8을 누르면 화면이 멈추고, 드래그한 영역이 편집기로 열립니다. 전체 화면 캡쳐와 이미지 열어 편집도 런처에 있습니다.

키도구 · 동작
V P H선택 · 펜 · 형광펜
R A T네모 · 화살표 · 글자
M E C모자이크 · 투명 · 자르기
I스포이드 (화면에서 색 고르기)
[ ]굵기 줄이기 · 늘리기
Ctrl+Z · Ctrl+Y되돌리기 · 다시 실행
Ctrl+C · Ctrl+S복사 · 저장
Delete선택한 주석 지우기

투명 도구는 드래그하면 그 영역을 지우고, 클릭하면 클릭한 색을 이미지 전체에서 투명하게 만듭니다. 자르기는 원본을 지우지 않고 남길 영역만 정합니다.

04움짤 녹화

  1. 런처에서 형식을 고릅니다. GIF는 어디서나 재생되고, MP4는 용량이 가볍고, WebP는 화질이 선명하고, WebM은 투명 영상입니다.
  2. F9을 누르고 녹화할 영역을 드래그합니다. 바로 녹화가 시작됩니다.
  3. 다시 F9을 누르면 멈추고 저장합니다.

투명 배경 녹화를 켜면 고른 색(그린스크린 등)을 지운 GIF · WebP · WebM이 나옵니다. 스포이드로 화면에서 색을 고르고 허용 범위로 얼마나 비슷한 색까지 지울지 정합니다. GIF의 투명도는 켜짐 · 꺼짐 두 단계라, 부드러운 가장자리가 필요하면 WebP나 WebM을 쓰세요.

05방송에서 클립 만들기

런처의 하이라이트 찾기를 누르면 창 하나에서 찾고, 다듬고, 내보냅니다.

준비물

  • 영상: 다시보기 파일.
  • 채팅: 채팅 다시보기 파일. 없다면 아래 명령으로 받습니다.
  • 정보(선택): 원본 제목과 주소가 들어 있어 설명란을 만들 때 씁니다.
stream2clip.exe fetch "방송 주소" -o vod --video

vod 폴더에 영상, 채팅, info.json이 생깁니다. YouTube, CHZZK, SOOP 다시보기 주소를 받습니다.

다음 버전 주소로 바로 시작하기. 영상 칸에 방송 주소를 붙여 넣으면 채팅을 받아 장면을 찾고, 내보낼 때 체크한 구간의 영상만 내려받습니다. 지금 실행 파일에서는 명령줄의 stream2clip.exe auto "방송 주소" -o clips가 같은 일을 합니다.

찾고, 다듬고, 내보내기

  1. 하이라이트 찾기를 누릅니다. 채팅이 평소보다 몰린 곳이 타임라인에 표시되고 목록에 이유가 적힙니다.
  2. 구간의 가운데를 끌면 이동, 가장자리를 끌면 시작 · 끝이 바뀝니다. 긴 방송은 휠이나 더블클릭으로 확대합니다.
  3. 내보낼 구간만 체크하고, 오른쪽에서 레이아웃과 형식을 고릅니다. 미리보기에 결과가 보입니다.
  4. 클립 내보내기를 누릅니다. 클립, 자막 파일(.ass), 설명란(.txt)이 저장 폴더에 생깁니다.
레이아웃모양
blur방송 화면을 가운데 두고 위아래를 흐린 배경으로 채웁니다
center가운데를 세로로 꽉 채웁니다 (양옆이 잘립니다)
fit화면 전체가 보이도록 줄입니다
stack위에 아바타, 아래에 게임 화면. 자동 찾기가 아바타 위치를 찾아 줍니다

임계값을 낮추면 더 많이, 높이면 확실한 장면만 찾습니다. 노래 구간을 켜면 노래와 겹치는 하이라이트를 표시하거나 뺍니다. 노래 방송은 곡 저작권 때문에 클립이 제한되는 경우가 많습니다.

06자막과 번역

  • 자막 파일 사용: 자막 칸에 SRT · WebVTT 파일을 넣습니다. YouTube 자동 자막도 됩니다(fetch에 --subs ja를 더하면 함께 받습니다).
  • 카라오케: 말하는 단어를 따라 색이 켜집니다. 단어 시각이 있는 자막에서만 됩니다.
  • 받아쓰기(Whisper): 자막이 없을 때 음성에서 만듭니다. 실행 파일에는 들어 있지 않아 파이썬 설치가 필요합니다.
  • 번역: stream2clip에는 번역 서비스가 들어 있지 않습니다. 번역기 목록에서 번역기 파일 고르기로 translators\openai_compatible.py를 고르면 내 PC의 Ollama 같은 OpenAI 호환 주소로 번역합니다. 번역 품질은 고른 모델에 달려 있습니다.
  • 용어집: 원문,번역 두 칸짜리 CSV로 이름처럼 자주 틀리는 말을 고정합니다. 원문 병기는 원문 위에 번역을 한 줄 더 둡니다.

07OBS 리플레이

방송 중 "방금 그 장면"을 바로 움짤로 만듭니다. OBS가 최근 몇십 초를 기억해 두는 리플레이 버퍼를 씁니다.

OBS에서 한 번만 해 두기

  1. 설정 → 출력 → 리플레이 버퍼에서 리플레이 버퍼를 켭니다. 새로 설치한 OBS는 꺼져 있습니다.
  2. 도구 → WebSocket 서버 설정에서 서버를 켜고 비밀번호를 확인합니다.
  3. 방송을 시작할 때 리플레이 버퍼 시작을 누릅니다.

stream2clip에서

  1. 런처의 연결 설정에 OBS의 비밀번호를 넣습니다. 비밀번호는 저장하지 않으므로 실행할 때마다 넣습니다.
  2. 마지막에서 남길 길이를 정하고 리플레이 저장을 누릅니다. 녹화 설정의 형식과 크기로 저장됩니다.
  3. F10을 체크해 두면 어느 프로그램에서든 F10으로 저장합니다. 켜 둔 동안 다른 프로그램은 F10을 받지 못합니다.

08라이브 모드 다음 버전

방송 중에 채팅을 지켜보다가 급증하면 OBS 리플레이를 저장하고, 그 장면을 약 35초 클립으로 잘라 둡니다. 지금은 파이썬 설치의 명령줄에서 씁니다.

stream2clip live "https://www.youtube.com/watch?v=VIDEO_ID" -o clips
  • OBS 리플레이 버퍼의 최대 리플레이 시간을 60초 이상으로 두세요. 기본값 20초로는 장면 앞부분이 남아 있지 않습니다.
  • 덜 저장하게 하려면 --threshold(기본 3.5)를 올립니다.
  • --no-obs는 저장 없이 급증만 알려 주고, --simulate 채팅파일은 끝난 방송에서 언제 발동했을지 보여 줍니다.
  • YouTube 라이브 주소를 받습니다. CHZZK · SOOP 라이브 채팅을 직접 받는 기능은 아직 없습니다.

09명령줄로 쓰기

앱이 하는 일은 모두 stream2clip.exe로도 됩니다. 여러 방송을 한꺼번에 처리할 때 편합니다.

명령하는 일
fetch방송 주소에서 정보 · 채팅(과 영상 · 자막)을 받습니다
auto영상 + 채팅, 또는 주소 하나로 하이라이트를 찾아 클립까지 만듭니다
highlights · clips찾기와 내보내기를 따로 합니다
convert영상의 구간 · 영역을 잘라 GIF · WebP · MP4로 바꿉니다
record · capture화면 영역을 녹화 · 캡쳐합니다
replayOBS 리플레이 버퍼를 저장해 클립으로 만듭니다
check설명란을 기획사 가이드라인 항목과 대조합니다
 
stream2clip.exe auto vod\video.mp4 --chat vod\VIDEO_ID.live_chat.json --info vod\info.json -o clips
stream2clip.exe convert vod.mp4 --start 1:02:03 --end 1:02:18 --width 480 -o highlight.webp

옵션 전체는 stream2clip.exe 명령 --help, 더 많은 예시는 README에 있습니다.

10막혔을 때

증상확인할 것
실행이 막힙니다서명이 없어서입니다. Smart App Control이 켜진 PC라면 파이썬 설치를 쓰세요
ffmpeg를 찾지 못합니다ffmpeg를 설치한 뒤 프로그램을 다시 열거나, ffmpeg.exe · ffprobe.exe를 실행 파일 옆에 둡니다
하이라이트가 0개입니다임계값을 낮춰 보세요. 채팅 파일이 그 방송의 것인지도 확인합니다
YouTube에서 "로그인하라"고 합니다명령줄에서 --cookies-from-browser chrome처럼 쿠키를 넘깁니다
"리플레이 버퍼가 없습니다"OBS 설정 → 출력에서 리플레이 버퍼를 켜고, 방송 화면에서 시작을 누릅니다. 장면이 비어 있으면 OBS가 시작하지 않습니다
OBS에 연결되지 않습니다WebSocket 서버가 켜져 있는지, 비밀번호와 포트(기본 4455)가 맞는지 봅니다
F8 · F9가 듣지 않습니다다른 프로그램이 같은 키를 먼저 잡고 있으면 그렇습니다. 그 프로그램을 닫고 다시 실행합니다

여기에 없는 문제는 GitHub 이슈에 남겨 주세요.

11올리기 전에

클립은 원본 방송의 2차 창작입니다. 내보낼 때 가이드라인에서 기획사를 고르면 원본 제목과 주소를 맨 위에 둔 설명란을 만들고, 멤버십 한정 방송 · 아카이브 공개 여부 같은 항목을 점검해 알려 줍니다.

이 점검은 체크리스트일 뿐 법적 판단이 아닙니다. 올리기 전에 각 기획사와 방송인의 가이드라인 원문을 직접 확인하세요.
