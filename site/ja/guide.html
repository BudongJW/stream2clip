インストール

Windows用インストーラー

  1. リリースページからWindows用インストーラー(setup.exe)をダウンロードして実行
  2. 最初の画面で言語を選択: 韓国語、日本語、英語。選択した言語がインストーラーとアプリの表示言語として適用
  3. インストール先を確認。管理者権限は不要
  4. 追加タスクの画面で ffmpeg をダウンロード を選択したままインストール。動画変換に必要なffmpeg(115MB)をインストール中にダウンロード。ffmpegが既にあるPCではこの項目は表示されない
  5. スタートメニューからstream2clipを起動
  • ダウンロードを外した場合や失敗した場合: アプリの開始画面上部の ffmpeg をダウンロード ボタンで再実行
  • コンポーネントの確認: 開始画面右上の コンポーネント確認 で、機能ごとに必要なコンポーネントの有無と対処方法を表示。コマンドラインでは stream2clip setup
  • インストールせずに使用: zipファイルをダウンロードして任意のフォルダに解凍し、stream2clip-gui.exe を実行。ffmpegは開始画面の ffmpeg をダウンロード ボタンで準備
  • アプリの表示言語はインストール後もランチャー下部で変更可能
  • アンインストール: Windowsの設定のインストール済みアプリ一覧からstream2clipを削除。ダウンロードしたffmpegも一緒に削除

注記

  • コード署名は未適用。Windows SmartScreenの警告が表示される場合あり
  • Smart App Controlが有効な環境では実行がブロックされる場合あり。その場合はPythonパッケージを使用
  • ファイルの整合性は、リリースページのSHA-256値と下記コマンドの結果を照合して確認
Get-FileHash .\stream2clip-*-windows-x64.zip -Algorithm SHA256

Pythonパッケージ

  • 要件: Python 3.10以上、ffmpeg
  • 対応OS: Windows、macOS、Linux
pip install "stream2clip[gui,ingest,obs] @ git+https://github.com/BudongJW/stream2clip"
stream2clip gui

  • F8: 画面を静止し、ドラッグした範囲を編集画面へ送る

  1. ランチャーで出力形式、フレームレート、サイズを選択

ハイライトクリップの作成

ランチャーのハイライトを探すで検出、区間の調整、書き出しを行う。

入力

項目内容
動画アーカイブのファイルまたは配信URL
チャットチャットリプレイのファイル。配信URLの入力時は自動収集
情報任意。元配信のタイトルとURLを概要欄の作成に使用
字幕任意。SRT、WebVTTファイル

配信URLから開始

  • 動画欄に配信URLを入力すると、チャットリプレイと配信情報を自動収集
  • 書き出し時に、選択した区間の映像のみをダウンロード
  • 収集したデータは保存フォルダの sources フォルダに配信ごとに保管し、再実行時に再利用
  • プレビューは該当区間のダウンロード完了後に表示
  • 音量、笑い声、歌の区間の分析は動画ファイルの入力時に使用可能
  • 対応: YouTube、CHZZK、SOOPのアーカイブ

作業手順

  1. ハイライトを探すを実行。チャット反応が通常より高い区間をタイムラインと一覧に表示
  2. タイムラインで区間を調整。中央のドラッグで移動、端のドラッグで開始と終了を調整、ホイールまたはダブルクリックで拡大
  3. 書き出す区間を選択し、レイアウトと形式を指定
  4. クリップを書き出すを実行。保存フォルダにクリップ、字幕ファイル(.ass)、概要欄(.txt)を作成

動画、チャット、情報、字幕のファイルはウィンドウにドラッグ＆ドロップで入力可能。

まとめ動画と編集ソフト連携

項目内容

状況説明クリップの最初の3秒、上に配信の話題を1行表示。配信タイトルの括弧の中のゲーム名などを使用
ちょい見せクリップの冒頭で一番盛り上がる2秒を先に見せてから本編 (MP4, WebM)
サムネイル最高の瞬間の近くで一番鮮明な場面に、タイトルの最初の部分を大きく入れた1280x720の画像 (clip_01.jpg)。アバターの位置を指定した場合はアバターを中心に拡大
タイトル、ハッシュタグクリップごとに最高の瞬間のセリフ、タレント名、事務所名からタイトルを提案。アップロード画面のタイトルの初期値。事務所のない韓国語タイトルは [名前] セリフ。ハッシュタグは概要欄の最後に追加(韓国語はCHZZK、SOOPのプラットフォームタグとキリヌキを加えて最大5つ)。誇張表現は点検で警告
コラボ相手、チャンネルリンクコラボ相手(カンマ区切り)はタイトルの最後に (w/名前)。チャンネルリンクは概要欄の元チャンネルの行の下に追加。連絡文を選ぶと、ガイドラインのない配信者向けの一文を追加。概要欄はタイトルと同じ言語で書き、配信日の行を含む
アップロードのカテゴリアップロード画面のカテゴリ。自動は元配信がゲーム配信ならゲーム、それ以外はブログ。手動でも選択可能
エフェクト最高の瞬間1か所だけに短いズームと字幕の単語の強調(控えめ)、チャットの反応タグを追加(バラエティ)。音が大きくなる瞬間や VTube Studio のホットキーを押した瞬間がはっきりしなければ入れない。動きを減らす選択時はズームの代わりに単語をより大きく強調
再利用コンテンツの点検字幕、状況説明、ちょい見せなしで切り出しただけのクリップを警告。YouTube の再利用コンテンツのポリシー上、投稿前に編集者自身の解説や字幕の追加が必要

検出オプション

  • しきい値: 低いほど検出区間が増加、高いほど反応の大きい区間のみ検出
  • 最大: 検出する区間数の上限
  • 歌の区間: 歌と重なる区間を表示または除外。歌配信は著作権の都合でクリップ作成が制限される場合が多い

配信データの一括ダウンロード

動画全体が必要な場合は、下記コマンドで動画、チャット、配信情報を vod フォルダに保存。

stream2clip.exe fetch "配信URL" -o vod --video

OBSリプレイの保存

OBSのリプレイバッファに保持された直近の区間を保存し、クリップに変換。

OBSの事前設定

  1. OBS設定の出力メニューでリプレイバッファを有効化。新規インストール時の初期値は無効
  2. OBSツールメニューのWebSocketサーバー設定でサーバーを有効化し、パスワードを確認
  3. 配信開始時にOBSでリプレイバッファを開始

stream2clipの設定と使用

  1. ランチャーの接続設定にOBSのパスワードを入力。パスワードは保存しないため、起動のたびに入力
  2. 最後ので残す長さを指定し、リプレイを保存を実行。画面録画設定の形式とサイズで保存
  3. F10を選択すると、他のプログラムの使用中も F10 で保存。使用中は他のプログラムがF10の入力を受け取らない

ライブモード

配信中のチャット急増を検知してOBSリプレイバッファを保存し、その場面を約35秒のクリップとして作成。

前提条件

  • OBSリプレイバッファの実行とWebSocket接続設定の完了
  • OBSの最大リプレイ時間を60秒以上に設定。初期値の20秒では場面の冒頭が欠落

使用手順

  1. ランチャーのライブモード欄にYouTube、Twitch、CHZZK、SOOPのライブURLを入力
  2. 感度を選択。高は小さな急増でも保存、低は大きな急増のみ保存
  3. ライブモード開始を実行。チャット急増時に保存フォルダへ live_日付_時刻 形式のクリップを作成
  4. ライブモード停止で終了

動作基準

  • 5秒単位のチャット量、参加者数、反応語彙、有料メッセージを直前の15分と比較
  • 開始後2分間は基準の収集のみ。クリップ間の最小間隔は90秒
  • 急増の8秒前を場面の時点と判断し、前20秒と後10秒を含める
  • 配信者またはモデレーターがチャットに !clip を入力すると、急増の有無に関係なく即時保存
  • 対応: YouTubeライブ配信、Twitch、CHZZK、SOOP。CHZZK、SOOPの成人認証配信とパスワード配信は対象外

コマンドラインでの実行

stream2clip.exe live "https://www.youtube.com/watch?v=VIDEO_ID" -o clips
オプション機能
--threshold発動基準。初期値3.5。高いほど保存回数が減少
--no-obs保存せずに急増の発生のみ出力
--simulate終了した配信のチャットファイルで発動時点を確認
--delay視聴者の反応の遅れ。配信者は配信の遅延分を加算して使用

配信レコーダー

配信中のチャット、マーク、OBSのシーン、VTube Studioのアバターの位置と表情をセッションファイルに記録し、配信後の切り抜き制作に使用。映像はOBSが録画。

使い方

  1. スタート画面のクリップ欄で配信レコーダーを開く
  2. 自分のチャンネルの配信URLを入力し、OBSとVTube Studioの使用を選択。VTube Studioは設定でAPIをオンにし、初回接続時にVTube Studioに表示されるプラグイン許可画面で許可
  3. OBSでVTube Studioを表示しているソース名を入力。切り抜き制作時のアバター領域の自動指定に使用
  4. 記録開始を実行。残したい場面で今をマークまたはF11(オン時)
  5. 配信終了後に記録停止、ハイライトを探すでハイライト画面にセッションファイルを入力

記録内容と用途

  • チャットとマーク: チャットリプレイを取得せずにハイライト検出。マークした場面は必ずクリップに含む
  • OBSのシーン: 待機画面、エンディングなど指定したシーンのハイライトを除外
  • VTube Studioの輪郭とOBSでの配置: 縦型クリップのアバター領域を指定
  • 映像の0秒はOBSの配信開始時点。配信の記録がなければ録画開始時点
  • 視聴者投票: 視聴者3人が30秒以内に!clipを入力するとマークとして記録
  • OBSウィジェット: OBSのブラウザソースにhttp://127.0.0.1:8790/widgetを追加すると投票状況とマークを配信画面に表示
  • チャットの投稿者は識別できない値でのみ記録し、ファイルはこのPCにのみ保存

ハイライト画面の設定

  • セッション欄にセッションファイルを入力。チャット欄に入れた場合や画面にドロップした場合もセッション欄に移動。チャット欄が空の場合はセッションのチャットとマークで検出
  • 0 秒の基準: プラットフォームのアーカイブはOBS配信開始、OBSの録画ファイルはOBS録画開始を選択。動画が基準より遅く始まる場合はその差を秒単位で入力
  • 除外シーン: シーン名の一部をカンマ区切りで入力。半分以上がそのシーンに含まれるハイライトを除外
  • アバターの動き (実験): アバターの動きが大きい場面に点数を追加
  • 書き出し設定のアバター行のセッションから: チェックしたハイライト区間の輪郭でアバター領域を入力
  • 音声トラック: OBSでマイクを別トラックに録音した場合はそのトラック番号を選択。字幕認識、無音区間、音量の判定に使用し、クリップの音声は変更なし

stream2clip.exe session record --chat "https://chzzk.naver.com/live/CHANNEL_ID" --vts --vts-source "VTube Studio"

トラブルシューティング

症状対処
プログラムの実行がブロックされるコード署名未適用によるブロック。Smart App Controlが有効な環境ではPythonパッケージを使用
新バージョンの通知開始画面の上部に表示。ダウンロードページを開くで新しいインストーラーを取得、通知をオフで確認を停止。確認は1日1回以内で、ユーザー情報は送信しない
ffmpegが見つからないアプリの開始画面の ffmpeg をダウンロード ボタンを使用。コマンドラインでは stream2clip setup --ffmpeg。自分でインストールした場合は 再確認 ボタン、またはプログラムを再起動
区間が検出されないしきい値を下げて再実行。チャットファイルが該当配信のものか確認
YouTubeでログインを要求されるコマンドラインで --cookies-from-browser chrome オプションによりブラウザのCookieを渡す
リプレイバッファが動作していないOBS設定の出力メニューでリプレイバッファを有効化して開始。シーンにソースがない場合、OBSはバッファを開始しない
OBSに接続できないWebSocketサーバーの有効化、パスワード、ポート(初期値4455)を確認
ライブモードのクリップの冒頭が欠けるOBSの最大リプレイ時間を60秒以上に変更
F8、F9が動作しない同じキーを使用する他のプログラムを終了して再起動

その他の問題はGitHubのIssueに登録。

著作権とガイドライン

  • クリップは元配信の二次創作物に該当し、原著作者と所属事務所のガイドラインの適用対象
  • 書き出し設定のガイドライン一覧で事務所を選択すると、元配信のタイトルとURLを含む概要欄を作成し、確認項目を点検
  • 確認項目: メンバー限定配信の該当有無、アーカイブの公開有無、チャンネル登録の有無、AI使用の表記
  • 確認結果は参考資料であり、法的判断ではない。アップロード前に各事務所と配信者のガイドライン原文を確認
