ダウンロード

配布形態Windows用インストーラー(setup.exe)または圧縮ファイル(zip)。アプリ stream2clip-gui.exe、コマンドラインツール stream2clip.exe を同梱
対応環境Windows 64ビット。Windows 11で検証
必須コンポーネントffmpeg (動画変換)。インストール中にダウンロード
インストール方法インストーラーの実行時に言語を選択(韓国語、日本語、英語)。管理者権限は不要。zipは解凍して実行
コード署名未適用。Windows SmartScreenの警告が表示される場合あり。Smart App Controlが有効な環境ではPythonパッケージを推奨
整合性の確認リリースページのSHA-256値と照合
別途インストールの機能字幕の文字起こし(Whisper)、YouTubeアップロードはPythonパッケージで提供
その他のOSmacOS、LinuxはPythonパッケージでインストール。Python 3.10以上が必要

インストール手順

  1. インストーラーをダウンロードして実行
  2. 最初の画面で言語を選択。選択した言語がアプリの表示言語として適用
  3. 追加タスクの画面で ffmpeg をダウンロード を選択したままインストール
  4. スタートメニューからstream2clipを起動

インストールせずに使用: zipファイルをダウンロードして解凍し、stream2clip-gui.exe を実行。ffmpegは開始画面のボタンでダウンロード

Pythonパッケージ

pip install "stream2clip[gui,ingest,obs] @ git+https://github.com/BudongJW/stream2clip"

主な機能

ハイライト検出
  • チャット量、参加者数、反応語彙、有料メッセージを配信ごとの平均と比較して区間を検出
  • タイムライン上で区間の移動と長さの調整
  • 音量分析、歌の区間の表示と除外
配信URLの入力
  • 配信URLだけでチャットの収集とハイライト検出
  • 選択した区間の映像のみダウンロード
  • YouTube、CHZZK、SOOPのアーカイブに対応
縦型クリップと字幕
  • 9:16レイアウト5種: blur、center、fit、stack、pip
  • カラオケ字幕、字幕翻訳、用語集
  • 元配信のタイトルとURLを含む概要欄の自動作成
画面キャプチャと録画
  • F8 範囲キャプチャと注釈の編集
  • F9 画面録画: GIF、MP4、WebP、WebM
  • 指定した色を除去する透過背景録画
OBS連携とライブモード
  • F10 リプレイバッファの保存とクリップ変換
  • ライブモード: 配信中のチャット急増時にリプレイを自動保存してクリップを作成
ガイドラインの確認
  • 事務所ごとの確認項目: ホロライブ、にじさんじ、ぶいすぽっ!、あおぎり高校
  • 確認結果は参考資料であり、法的判断ではない
